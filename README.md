# Rubik kubiklari (APK)

1. Bu papkadagi hamma narsani GitHub repoga yuklang (`main` branch).
2. GitHub → **Actions** → "Build APK" tugagach (3–6 daqiqa) pastdagi **Artifacts** bo'limidan `rubik-kubiklari-apk` ni yuklab oling.
3. Zip ichidagi `app-debug.apk` ni telefonga o'rnating ("noma'lum manbalardan o'rnatish" ruxsati kerak).

Sayt fayli: `www/index.html`. O'zgartirib push qilsangiz, APK qayta yig'iladi.
